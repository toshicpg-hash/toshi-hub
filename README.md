# TOSHI HUB

予定・ToDo・ガント・入出金管理をまとめた個人用PWAです。

- 公開画面: https://toshicpg-hash.github.io/toshi-hub/
- ソース: https://github.com/toshicpg-hash/toshi-hub
- 公開元: GitHub Pages（`main`ブランチ）
- データ保存: 端末内のブラウザ保存領域

更新時は `index.html` の表示バージョン、`sw.js` のキャッシュ名、`manifest.json` の説明バージョンをそろえ、GitHub Pagesの公開成功まで確認します。
